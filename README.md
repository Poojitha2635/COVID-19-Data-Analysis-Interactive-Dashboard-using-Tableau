# COVID-19 Data Analysis & Interactive Dashboard using Tableau

## Project Overview
This project presents an interactive Tableau dashboard built using a cleaned COVID-19 dataset. The dashboard helps visualize pandemic trends, monitor key performance indicators (KPIs), and analyze cases, recoveries, deaths, testing, and regional performance.

--

## Objectives
- Clean and prepare COVID-19 data.
- Analyze pandemic statistics.
- Create an interactive Tableau dashboard.
- Visualize key health metrics.
- Support data-driven decision-making.

# Project Workflow

### Step 1: Data Collection
- Imported the COVID-19 dataset into Excel.



### Step 2: Data Preparation
- Imported the cleaned dataset into Tableau.
- Verified field types.
- Created calculated fields where required.

### Step 3: Dashboard Development
Created an interactive dashboard with:
- Total Tests
- Total Positive Cases
- Total Negative Cases
- Active Cases
- Recovered Cases
- Death Cases
- Recovery Rate (%)
- Death Rate (%)
- Cases by Region
- Daily Trend Analysis

### Step 4: Interactive Features
- Region Filter
- Date Filter
- Interactive Charts
- KPI Cards
